# 🧠 LeetCode Patterns & Problem Solving

This repository contains my solutions to LeetCode problems,
organized by patterns and explained with clear reasoning.

## 🎯 Goal

The goal is not just solving problems, but understanding patterns,
improving problem-solving skills, and preparing for technical interviews.

---

## 🧩 Patterns Covered

- Two Pointers
- Sliding Window
- Hashing
- Stack & Queue
- Trees & Graphs
- Dynamic Programming (in progress)

---

## 🛠 Approach

For each problem, I include:

- Pattern identification
- Step-by-step explanation
- Time and space complexity
- Key insights
- Common mistakes

---

## 💡 Example Structure

Each problem is documented like this:

- **Pattern:** Sliding Window  
- **Idea:** Expand and shrink the window based on a condition  
- **Complexity:** O(n)  
- **Key Insight:** Avoid resetting the window, shrink it instead
